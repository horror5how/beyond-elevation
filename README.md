# be-fearn

Beyond Elevation homepage rebuilt in the minimal, image-led editorial style of fearn.ai.

- `index.html` — single page
- `assets/style.css` — design system (Newsreader / IBM Plex Mono / Inter)
- `assets/site.js` — hero wafer animation
- `assets/img/` — black-and-white photography generated with Higgsfield (nano_banana_pro), plus real client and founder headshots carried over from the live site

Hero animation: a silicon wafer die grid. Squares get claimed one at a time — semiconductors are the most patent-dense industry there is, and a die grid reads as a board being taken square by square.

Local preview: `python3 -m http.server 4813`
